# RL 环境设计笔记 (W3 产物)

> 用途: 面试被问"你的 RL 环境怎么设计"时的完整弹药
> 填写方式: 每题语音作答 -> AI 批改 -> 誊入

---

## 1. 观测空间 (状态: 已填, 2026-09-05)

- 21 维 = 关节角(6) + 关节速度(6) + 手位置(3) + 目标位置(3) + 相对位置(3)
- 关节状态供策略感知当前姿态; 手/目标/相对位置直接服务"减小距离"的目标
- 缺了相对位置, 策略要自己心算差值; 缺关节速度, 无法感知动量

## 2. 动作空间 (状态: 已填)

- 6 维末端速度: 任务目标定义在末端空间, 动作与任务同构
- 关节空间动作冗余、难学; 末端速度经 OSC 映射为关节命令
- 归一化 [-1,1] × 速度上限: 神经网络喜欢小范围输入, 也方便裁剪安全限速

## 3. 奖励函数 (状态: 已填)

- ① 距离减少塑形 (-2·Δd): 稠密信号, 引导逼近
- ② 近距离指数奖励 (0.2·exp(-40d)): 越近奖励越大, 解决"最后几厘米没梯度"
- ③ 动作惩罚 / ④ 关节速度惩罚: 正则, 抑制抖动与无效动作
- 成功 (2cm 内) 额外 +20, 一局终止 —— 稀疏但明确的终点信号

## 4. 可达性设计 (状态: 已填)

- 采样以初始 TCP 为中心、半径 8~25cm
- 行程预算: 2s × 0.15 m/s = 30cm —— 目标必须落在预算内, 否则不可达、奖励恒零
- 实际改进: 采样方式一改, PPO 成功率 2/10 -> 10/10

## 5. 训练与结果 (状态: 已填)

- PPO (on-policy 策略梯度 + clip 限幅), n_steps=2048, lr=3e-4
- 1M 步 ~30 分钟; entropy 单调下降 = 策略收敛
- 成功率 150/150 (50局×3种子, 2cm 口径, 落点 1.86±0.09cm); 同任务 VLA v4.5 为 50/50
  (9cm 口径, 3 分钟示教 + RGB-D 检测), **2cm 口径下成功率 0~10% (三次训练:
  0/50、5/50、0/50), 最近 4.56±1.93cm (v4 真值)**
  —— 严格证据是同类指标对照: 示教 ~10% 回合终止 <2cm ↔ 策略 2cm 成功率 0~10%;
  示教终点 4.6±2.4cm 与策略最近距离同量级 (指标不同义, 不作等式);
  检测误差 (修复版 ~5cm) 是第二层噪声; 两种口径不可直接比
