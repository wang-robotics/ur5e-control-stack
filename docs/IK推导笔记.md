## 一、正运动学 FK (状态: 已填, 2026-08)

1. **定义**: 输入 = 关节角度 (θ1, θ2, ...); 输出 = 末端(手)的位置(与姿态)。
   FK 是确定性函数: 一组角度只对应一个位置, 所以总有唯一答案。
2. **推导四步法**: ①贴坐标系 → ②每关节一个 4×4 → ③连乘 → ④读结果。
3. **两连杆公式**: x = L1·cosθ1 + L2·cos(θ1+θ2); y = L1·sinθ1 + L2·sin(θ1+θ2)。
   - L1·cosθ1 = 连杆1 在 x 轴的投影; θ1+θ2 是连杆2 相对世界的累积转角。
   - ★ 易错点: θ 从 x 轴起量 → x 配 cos, y 配 sin。自检: θ=0 时手应在 (L1+L2, 0)。
4. **平移之谜**: 关节只转; 4×4 里的平移 = 棍子(连杆)的固定长度。
   转动定方向, 棍长定距离。
5. **矩阵 vs cos/sin**: 轴少(2连杆平面)用三角公式(快、直观、面试黑板题);
   多轴/3D/带姿态用矩阵(唯一可行、可扩展、是 IK 与雅可比的语言)。

## 二、逆运动学 IK 概念 (状态: 已填, 2026-08; 3/4题需复习)

1. **关系**: IK 是 FK 的反问题 (给位置求角度)。FK 是确定性函数 → 唯一解;
   IK 可能无解 ((3,0) 超出臂长) 或多解 ((1,1) 肘上/肘下; (0,0) 折叠时无穷多解=奇异)。
2. **多解怎么选**: 选离当前位形最近的解 (关节动最少); 附加: 中途不翻转、不碰撞。
   ★ 数值法从当前姿势出发迭代, 自然收敛到最近解 —— 免手动选解。
3. **解析法 vs 数值法**:
   - 解析法: 公式直接解 (余弦定理+atan2), 单次极快、精确; 但只对特定构型有公式,
     6轴3D 公式爆炸且易错; 多解要手动管理 (±号)。
   - 数值法: 迭代逼近 (误差→雅可比→修正), 通用(任何臂同一套代码)、
     鲁棒(λ 防奇异)、免选解; 代价: 迭代(仍便宜)、近似(容差 0.1mm 级)、依赖初值。
   - 项目选择: 通用 + 鲁棒 + 免选解 (不是因为精度要求低! 精度足够高)。
4. **success 开关**: IK 可能无解, 必须诚实报告 (不硬塞错答案);
   调用方靠它决定报错停下还是继续; 原则: 响亮早死 > 安静烂尾。

## 三、雅可比 (状态: 已填, 2026-08)

1. **物理意义**: 灵敏度对照表 J(q) —— 每列 = "只转关节 i (1 rad/s), 手获得的速度"
   (列 i 的前 3 行 = 线速度, 后 3 行 = 角速度)。是位形 q 的函数, 随姿势变化。
2. **数值法**: 每个关节拨 ±eps, 量手位移, 斜率填列 (中心差分, 12 次 fk, 代价可忽略)。
   优点: 任何机器人通用、免推导; 缺点: 每次填表要"拨 12 下"+微小数值误差。
3. **解析法**: J_i = u × (p_end − p_i) —— u=单位转轴向量, 括号=力臂向量(从关节i到末端,
   不是到基座!), 叉乘=该关节转 1 rad/s 时手端速度。等价于 FK 公式对 θi 求偏导
   (2连杆例: ∂x/∂θ1 = -L1s1-L2s12 ...)。换机器人要重推 (FK 不同 → 导数不同)。
4. **奇异位形**: 某列变零 (折叠臂: 力臂为零 → J1=0), 秩降 (2→1), 丢失方向;
   DLS 表现: 安静地给 0 (不爆炸)。物理感觉: 转伞柄伞心不动。

## 四、DLS 与伪逆 (状态: 已填, 2026-08)

1. **基本方程**: J·dq = v (关节速度→手速度)。反解 dq: 想要手速度 v, 关节该多快。
2. **为什么需要伪逆**: 真逆只属于方且满秩的矩阵; ①J 非方阵 (3×6) ②方阵但奇异
   (det=0, 折叠实验) —— 两种场景真逆都不存在, 伪逆顶班。
3. **伪逆推导三步**: ①最小解必在 J 行空间 → dq = Jᵀα ②代入: J·Jᵀα = v → α = (JJᵀ)⁻¹v
   ③dq = Jᵀ(JJᵀ)⁻¹v。最小范数 = "关节动得最少"的分工。
4. **λ 三个角色**: 防爆炸(保证可逆) + 限速(奇异附近压制解) + 权衡(太大任务打折扣,
   太小奇异处打滑); 甜蜜点靠扫掠实验 (0.01 打滑 / 0.05 平衡 / 0.5 爬行)。
5. **对码**: robot.ik 的 dq = jac.T @ solve(jjt + reg, err):
   jac.T=Jᵀ, jjt=JJᵀ, reg=λ²·I, solve=乘逆, err=v (误差向量当速度指令: 远→快, 近→慢, 到点→停)。

## 五、实验证据 (状态: 已填, 2026-08; λ方向需复习)

1. **奇异脱困 (FLICK 扫掠)**: 0=永远卡死(完美对称无扰动); 0.01=慢脱困(1.7s起飞,4.5s到位);
   5=快脱困(0.72s起飞)。结论: 折叠点是不稳定平衡, 任意 ε>0 扰动最终脱困,
   无"最小甩力", 只有"甩力越大起飞越早"。
2. **λ 扫掠**: 0.01=太锐, 起飞前打滑摆错方向, 后段极快; 0.05=平衡平滑;
   0.5=解被稀释, 全程爬行(6s挪1mm)。结论: **λ 越大解越软越慢**; 甜蜜点 0.05。
3. **可操作性**: m = √det(JJᵀ) (方阵=|det J|), = 手的综合运动能力;
   奇异时=0 (病危), 越舒展越大 (健康); 实验里 0.0000→0.2966 是脱困心电图。

## 六、面试速答卡 (状态: 已填, 2026-08)

- **"FK 和 IK 分别是什么?"**
  FK = 由关节角算末端位姿, 确定性映射, 唯一解; IK = 由末端位姿反求关节角, 可能无解/多解。
- **"你的 IK 用什么方法? 为什么不用解析解?"**
  用数值迭代 DLS (算误差→雅可比→修正→循环)。解析解只对特定构型有公式,
  6轴3D 推不动且易错; 数值法通用、鲁棒 (λ 防奇异)、自动收敛到最近解。
- **"DLS 的 λ 怎么选?"**
  太小→奇异附近解过大、数值振荡; 太大→跟踪慢、精度降; 工程上在 1e-2~1e-1 量级按任务扫掠定甜蜜点。
- **"奇异位形是什么? 你怎么处理?"**
  某方向运动能力丢失 (雅可比降秩)。λ 让解保持有限不爆炸, 但丢失方向仍动不了;
  脱困靠换初始解、重新规划或利用冗余 (7轴零空间)。
