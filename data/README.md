# 数据集说明 (Data)

本目录**不存放数据文件** —— 示教数据集约 1.09 GB, 不进 Git 仓库。
数据通过脚本**可复现**, 这比附带大文件更有价值 (也符合本项目的可复现原则)。

## 1. 数据集构成

| 文件 (复现后生成) | 内容 | 规模 |
|---|---|---|
| `datasets/teleop/*.npz` | 键盘遥操作示教: 每条含 `images`、`actions` (末端速度)、`goal` | 24 条真示教 + 12 个自测文件 (后者已剔除) |
| `datasets/vla_dataset.npz` | 合并后的训练集 (发呆帧裁剪后) | 4703 帧 |
| `datasets/vla_dataset_clean.npz` | 对照实验用的干净子集 (仅 14 条优质示教) | — |

## 2. 如何复现

```bash
# ① 采集示教 (键盘遥操作, 松键保存; 距目标 <9cm 停 2 秒自动保存)
python scripts/teleop_collect.py

# ② 预处理 (合并 + 发呆帧裁剪 + 每帧附目标)
python scripts/preprocess_vla.py

# ③ 训练行为克隆策略
python scripts/train_vla.py --epochs 25 --move-weight 3.0
```

## 3. 关键统计 (报告引用用)

- 24 条真示教 = 14 条自动保存 (终点 <9cm) + 10 条手动保存 (终点 10~31cm);
- 物理回放测得的示教终点: **4.6 ± 2.4 cm** (n=14 自动保存);
- 示教中约 **10%** 的回合能停进 2cm —— 这条统计是解释"行为克隆上限"的关键。

> 评估协议: `--gain 1.5 --no-ema`, 随机种子 42 (目标序列固定),
> 成功 = 阈值内停 1 秒 (50 个控制周期), 每局上限 500 步 (10 秒)。
